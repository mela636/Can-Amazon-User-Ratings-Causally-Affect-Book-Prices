# Can-Amazon-User-Ratings-Causally-Affect-Book-Prices
Using Kaggle's Amazon Top 50 Bestsellers data (n=550), I regressed price on user ratings, controlling for genre, log reviews, and repeat-bestseller status. Ratings showed no significant effect (p=0.94); neither did review counts. Genre dominated: nonfiction cost $2.54 more than fiction, suggesting publisher norms set prices, not consumers.
